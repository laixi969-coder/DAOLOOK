# DAOLOOK 封面能力接入评估

核验日期：2026-09-23。范围：仓库文档、目录、许可证声明、部分生成脚本，以及 DAOLOOK 现有实现。未运行第三方生成任务，未验证点击率提升。本文记录接入前评估；后续内置实现进度见文末。

## 结论

技术上可以接入，但需要将本地 Agent Skill 改造成后台可版本化的策划与渲染服务。建议优先建设“封面策略 + 可控中文排版 + 2–3 个候选版本 + 质量检查”，再根据授权情况接入现成资源。

Stars 表示仓库关注度，不能当作使用人数或流量效果证据。三个主要项目即时 stars 为 7211 / 407 / 189；排名不是本评估依据。

阿囤囤当前技能明确使用柔和浅黄 #FDFFA7，并明确排除荧光黄，不应把 DAOLOOK 的荧光黄绿 UI 配色直接套给所有封面。

归藏使用真实字体排版能避免模型“画字”造成的字形错误，但仍需检查文案本身、字体缺字、截断和溢出，不等于绝对不会错字。

## DAOLOOK 现有差距

`server/adapters.py:cover()` 的真实模式目前只将方向名称和封面文案拼成一句提示，交给图像模型。演示模式使用简单 SVG 排版。前端方向为固定“极简文字 / 生活杂志 / 大胆撞色”。

尚缺：根据参考拆解与完整稿件选择吸引点、封面专用素材选择、真实人物/产品素材输入、可编辑文字层、缩略图可读性校验、输出统一尺寸与安全区、封面方案之间的效果反馈。

现有队列、积分冻结与退款、供应商主备路由、稿件及图片关联可以复用；不需要重写整个产品。

## 建议产品流程

1. 输入已有稿件、参考拆解、用户明确选择的品牌与图片资料。
2. 系统判断内容目标与证据是否足够，推荐 2–3 个不同切入角度，每个附一句理由，不让用户写 Prompt。
3. 只有缺少关键素材时要求补图。例如真人风需要本人/授权人物参考，产品测评需要真实产品图或截图；不能凭空伪造使用体验和结果。
4. 用户选方案、微调短标题，生成 1080×1440 的 3:4 封面。
5. 文本/截图型优先 HTML/CSS 或 Canvas 排版；照片型可使用真实照片或生成无字背景，再排中文。保留整图生成作为补充。
6. 自动检查文本溢出、字号、对比、脸部与产品遮挡、关键事实一致性；提供缩略图预览。通过后下载 PNG/JPG。
7. 在独立新任务中生成备选，不覆盖旧封面；按是否调用付费图像模型展示预计积分与失败退款规则。

前台第一期只开放三类：品牌杂志、方法清单、真人冲击。不要一次将所有模板名和技术参数交给用户。

## 实施拆分

- `CoverPlanner`：输入 source analysis / creation / selected assets，输出结构化 brief。brief 包含 hook、headline、supporting_text、style_id、layout_id、asset_ids、evidence_refs、missing_assets。
- `CoverRenderer`：分离 deterministic_layout 与 image_model，固定服务端模板，不执行任意模型生成脚本。接入真实中文字体、字体加载完成检测、图片裁切与统一尺寸导出。
- `CoverValidator`：检查标题内容与可视布局；渲染失败或不可读时修正/退款，而不是宣称成功。
- 数据记录增加 brief、style_version、renderer、尺寸、素材来源、验证结果、计费类型，沿用已有 task_id / creation_id。
- 各方向资源固定版本；管理员测试、发布和回滚。继续遵守 PRD，不在后台自动搜索/安装 GitHub Skill。
- 组图放到后续：先保证单封面质量，再做封面 + 内容页，避免扩大 V1 的交付范围。

## 如何验证是否带来流量

需要区分可读性改善与真实流量改善。先测试用户是否愿意采用、是否减少重新生成；再通过用户授权的后台数据或手工录入曝光、阅读/点击、收藏等结果。

有曝光量时才计算点击率；只有赞藏数时不能倒推 CTR。对同类型内容做分组比较，尽量控制账号、发布时间、主题和受众。若不能随机分配流量，只能作为方向性证据。不能用模型自评分替代真实效果，也不建议为测试反复发布同一笔记。

## 已执行的内置实现（2026-09-23）

DAOLOOK 已独立实现三个方向的中文 SVG 排版、关键词策划、可编辑文案、项目图片选择与裁切、预览/缩略图、PNG/JPG 导出、版本追加及质量提示。未复制上述仓库模板、提示词、脚本或图片，未安装外部技能；因此这次落地不依赖其运行时和外部授权。Vivi 18 风格库暂未打包。

初版策划使用稿件标题和正文关键词，提供理由，不是大模型或经过真实流量验证的推荐器。初版校验是结构和尺寸校验，不代表事实核验或人脸遮挡检测。单封面优先，组图和效果数据闭环待后续实现。
