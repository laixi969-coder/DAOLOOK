# 导出一篇已确认的小红书图文

1. 在稿件的「发布与反馈」中确认当前版本可发布，随后点稿件卡的「图文发布包」。
2. 查看封面和两张内页，点图片可以放大。默认依次使用这篇稿件关联的最多三张项目实拍图；只有一张时沿用同一张。可在预览中选择项目里的另一张照片。稿件未关联照片时先选择一张，项目尚无照片时先在项目资料中上传。
3. 展开「正文与话题」核对内容，点「复制正文」或「下载图文发布包 ZIP」。压缩包内含三张 1080 × 1440 PNG 和一份含标题、完整正文、话题的 UTF-8 文本。

封面使用当前确认版封面文字或标题重新排版。内页优先采用原稿完整段落；单段长文可按完整句子成组取用，保留紧随价格的适用条件。必要时使用该稿已有的行动引导、开头或可发布评论。内容不足两项时可从预览打开稿件，调整文字后重新确认。正文中的其余信息仍在 TXT 内。

预览与下载只读取当前项目。确认时同时记录稿件版本和所选文字资料；资料改价、删除或临时文字到期后，重新核对当前资料并确认，再打开预览。旧版留下的确认首次使用时也需核对一次，首次确认时间继续保留。下载前会再次核对稿件、资料和照片。此流程使用本地排版，不消耗模型积分。可用同一篇稿件从确认到完成打包的用时作为试点记录。
