# 第一优先升级与方法论（2026-10-31）

本轮补齐 [内容效果升级](内容效果升级.md)「第一优先」剩余三项 + PRD 9.5 看板两项，并发布 [Daolook 内容方法论 v1.0](Daolook内容方法论.md)。运行中的服务需重启，以创建 `asset_facts` 表、迁移 `rewrite`/`facts` 积分规则并发布新 Skill（旧生效版本自动归档，可在后台回滚）。

## 1. 生产看板补齐（PRD 9.5）

- `GET /api/workspace` 返回 `stats`：今日产出、按平台的内容方向配比、已发布数、手动效果合计（排除演示稿）。全项目口径，不受列表分页影响。
- 看板新增「今日产出 X 篇 · 节奏参考 6–8 篇/天」与「方向配比」两个统计块；某平台 ≥6 条只有一种方向时提示「不要整批只做一种岗位」。旧响应自动回退到已加载稿件口径。

## 2. 单问题追问（第一优先）

- 新模块 `server/intake.py`，确定性规则，一次最多一个问题，零模型成本：资料里出现多个不同价格 → 问以哪个为准；目标为下单且资料无价格/购买方式 → 问价格与入口；目标为咨询且资料无联系方式 → 问咨询方式。
- `POST /api/create`、`POST /api/original`（仅国内平台）命中时返回 `{ask}`；请求带 `answer`（≤500 字）则并入临时资料后正常入队，带 `skip_question: true` 或前端跳过则直接生成。海外平台与纯图片资料不参与。
- 前端弹单个问题模态框；同一账号+项目内已跳过的问题不再重复打断；回答后仍命中则自动跳过，绝不循环追问。

## 3. 资料结构化入库（第一优先）

- 保存或替换文本资料（品牌资料/产品信息/受众画像/账号/其他）后自动排队 `facts` 任务；图片与禁用词不参与。`POST /api/assets/{id}/facts` 手动重新整理。
- 模型按 Skill `asset_facts` 抽取最多 20 条要点，五类固定（卖给谁/卖什么/可信证据/常见顾虑/购买路径），每条必须携带逐字来自原文的 `quote` 出处，校验失败自动重试。重新整理整组替换；删除资料级联删除要点。
- 计费默认 0（后台「资料整理积分」可调）；真实调用受供应商费用预算保护；真实模式未配置模型时自动整理静默跳过。
- 国内再创作/自主创作的模型输入新增 `structured_facts`，引用校验沿用原文匹配。演示模式用明确标注的演示模板（只引用原文首句）。

## 4. AI 单条定向重写（第一优先）

- `POST /api/creations/{id}/rewrite`（project_id、revision、instruction 2–500 字）。仅限小红书/抖音稿件；已发布或已记录效果返回 409；乐观锁校验期望版本号。
- 新 Skill `xhs_rewrite`/`douyin_rewrite`：只按指令改，不引入新事实，保持方向/岗位/切角与评论结构。结算时再次校验发布状态与版本，期间被修改则失败退款；成功追加「AI 定向重写」版本，可在历史版本恢复。
- 计费走新积分规则 `rewrite`（默认 3，旧库迁移自动补齐，后台可调），冻结→结算→失败退款。演示模式输出明确标注的演示改写。
- 前端编辑器新增「AI 定向重写」区；有未保存的手动修改时先保存再重写。

## 5. 内容方法论 v1.0

见 [Daolook 内容方法论](Daolook内容方法论.md)：流量层（钩子要素/关键词卡位/收藏完读设计）、创意层（切角不重复/四种创意算子/真实感）、转化层（信任链/行动单点/评论区承接）。

- 创作 Skill 升级 v6（`skill_release_2026_10_31_methodology`，启动自动发布）；自主创作经运行时指令继承；定向重写保持方法论结构。
- `content_quality.methodology_hints` 新增结构性自检：标题钩子要素、开头具体细节、按目标的行动引导、置顶承接转化。每稿最多 3 条提示，在稿件卡「方法论自检」折叠区展示；**只提示不阻塞，不预测流量或转化**。
