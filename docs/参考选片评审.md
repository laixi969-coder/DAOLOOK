# 参考选片评审

## 国内参考前三条

博主和关键词入口先选有点赞、收藏或评论记录的作品。只有发布时间、粉丝数或人工拍法分的作品列为待核实候选，数量不足时在任务结果中按原序显示原片链接。点击「带入单条拆解」可用原链接继续，点击表单的「开始拆解」时才提交。自动拆解只按完成的有互动参考结算，缺少互动的条目退回预留积分。平台返回的零属于有记录。自主创作只将有互动记录的参考放进赛道样例。来源收藏中的「相对表现」排序也使用这一分组。

从同一账号或搜索接口按原始顺序保存完整候选列表。每条样本写一行 JSON，`response` 是该条平台详情的原始对象。同一列表使用相同的 `batch`，不同列表使用唯一批次名。编辑分别标记 `label`（0 普通、1 相对表现异常）和 `borrow`（0 不借用、1 可借用、2 优先借用）。`entry` 使用 `keyword` 或 `creator`。下面是格式示意。

```json
{"platform":"xhs","entry":"keyword","batch":"门店开业-第一批","split_group":"门店开业词组","url":"https://www.xiaohongshu.com/explore/example","observed_at":"2026-11-20T10:00:00+08:00","label":1,"borrow":2,"response":{"data":{"note_id":"example","title":"脱敏标题","interact_info":{"liked_count":55}}}}
```

```sh
python3 scripts/calibrate_ranking.py candidates.jsonl --holdout-group 门店开业词组 --output /tmp/daolook-ranking.json
```

可重复给 `--holdout-group`，也可用 `--split-key` 换成样本中的账号或日期字段。省略显式选择时按组名的稳定哈希留出约四分之一组，单组数据只做拟合。同一批次不能被拆开；训练集与留出集重复出现的作品会从训练集排除。留出标签独立保存，确定权重后再查看留出报告。旧样本的 `group` 仍可兼作批次。时间维度使用采样时的 `observed_at` 或提供的 `age_days`，没有采样时间则标成缺失。

`holdout.ranking` 对比来源原序、点赞顺序、当前规则和训练得到的候选权重。每个列表最多取三条，分别报告愿意借用的条数、可排位置和实际入选条数，候选不足会降低可排位置中的可用比例。NDCG@3 按借用等级和位置加权，只汇总有正例且整批已标注的列表。未标完的整批不计前三可用率；`borrow_labels`、`scored_records` 和 `holdout_samples` 给出覆盖量。训练 AUC 衡量相对表现标签的区分能力，未标注业务样本时无法判断参考质量是否提高。工具只生成报告。

## 海外候选抽审和回看

服务启动时会补齐随版本发布的公开原片与审片依据。升级已有实例时保留本地复审结论及已发布的片单。11 月 26 日更新版的 15 条入选原片、关键秒数及 11 月 25–26 日首屏逐条对照见[当期审片记录](海外推荐审片-2026-11-26.md)。

这些命令在服务所在机器运行。默认使用项目数据库，使用自定义数据库时在子命令前传 `--db 路径`。只有 `record` 会写入资料，且只能记录已知公开原片。

```sh
python3 scripts/review_references.py sample --scope unmatched --limit 12 --seed 第1周
python3 scripts/review_references.py sample --scope front --days 14 --limit 10 --seed 首屏盲评
```

`unmatched` 从未匹配的公开候选抽样，`front` 从最近实际展示过的首屏抽样。两者按原片去重并跳过已有人工判断的作品，输出只有原链接、标题和发布者。编辑观看抽到的原片，记录画面变化所在秒数、复拍道具、拍摄方法和拍法名称。未观看的作品保持待审。

```sh
python3 scripts/review_references.py record "$clip_url" keep --second 3.5 --change '纸盒转向镜头，露出店址' --props '手机、纸盒' --method '固定手机，手转纸盒，停一秒读店址' --mechanism '翻面指路'
python3 scripts/review_references.py record "$clip_url" reject --reason '变化依赖不可复用的场地装置'
python3 scripts/review_references.py report --days 14 --end 2026-11-26
```

同一链接再次录入会更新判断。通过审片的在库候选可出现在易拍片库和后续选片中，拍法引用会保留秒数、观察到的变化和道具。日刊优先选昨日未出现的作品，再考虑今日首次匹配、过往首屏和拍法多样性。已确定的首屏保持稳定，未通过审片的作品会从自动版撤下。已发布特刊和往期快照可继续回看。

日报按片单时区、当天对用户展示的最新一期计算。报告逐日给出首次匹配记录数、首次出现在已有归档首屏的原片数、与前一天共同出现的原片数和比例。若缺少某天归档，该天及跨缺口的重复率未知。采集状态显示完整、部分、失败或未知。只有当日有完整同步且没有首次匹配记录时显示零。旧库缺少逐日采集记录时仅能恢复保留的匹配记录和最近一次同步。可拍率使用期间首屏中**不同原片**的当前人工判断，通过数除以已审数，同时展示已审覆盖。没有人工判断时可拍率为空。
