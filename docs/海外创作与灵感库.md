# 海外创作与灵感库

## 当前版本：hiccai-pop v2.2.0 与资料上传

已同步上游 [f7c717f](https://github.com/laixi969-coder/hiccai-pop/tree/f7c717fcd4ec190f12271048a86e0ca98caf2382)。默认最后一镜首次可辨认产品；每条标注有人、仅手部或无人，三条默认约一半无人，用户明确要求优先。新方案保存首次揭晓镜号和拍法，默认每条完整覆盖 3–6 镜；这些内容可在结果页、TXT 与 CSV/XLSX 中查看。服务启动一次性升级海外 Skill，原版本归档；启动后的管理员修改不会被下一次启动覆盖。

海外创作表单已加入「上传创作资料」：

- 支持 TXT、MD、CSV、Word（.docx）、PDF，以及 PNG/JPG/WebP 图片或海报。每份最多 2 MB，一次最多 6 份，可混合上传。
- 文档提取文字后保存为项目资料；图片保留原图，显示缩略图。所有成功上传的资料自动选入本次创作，刷新后恢复勾选；取消勾选不删除资料。
- 上传期间禁止提交创作，部分失败时保留已经成功的资料；切换账号或项目后，旧上传结果不会写入新工作区。
- 选中的海报和图片通过现有多模态链路传给真实创作模型，需要供应商支持图片输入。演示模式只展示流程，不会理解图片；扫描版 PDF 请转成图片上传。

本轮验证：175 项 Python 测试、前端状态与创作工具测试、语法检查通过。浏览器完成文档与海报混合上传、缩略图、自动勾选、刷新恢复、390px 布局和演示创作；模型资料传递用受控响应验证，未实际调用付费模型。

以下 v2.1 与初次接入章节保留为变更记录，当前规则以本节和内置 v2.2 源文件为准。

海外创作每次交付 3 个独立建议，单平台也是 3 个不同故事；结果按建议编号全部展示。提交后清除沿用的收藏与工序筛选，避免新批次只有部分方案可见。演示模板分别采用尺度、目的和身份误判；真实模型须给出不同的切角、第一秒、误判与反转，重复结果会进入现有重试流程。此项为 Daolook 的交付升级，启动时一次性发布新提示词。

## hiccai-pop v2.1.0 更新

海外创作现使用 [hiccai-pop 提交 aef52aa](https://github.com/laixi969-coder/hiccai-pop/tree/aef52aa053916d0a0da5675c2a92c1090ec3bc12) 的完整 `SKILL.md`，本地副本为 `server/resources/hiccai-pop/SKILL.md`。后端新增 Daolook 的结构化交付约定，要求首秒画面、观众误判、公平伏笔、结尾反转、产品因果角色、收尾方式、具体制作路径和成本依据。每个分镜还要写实拍或 AI 的实现办法；默认最多六镜。后台原有已发布的海外 Skill 会在首次启动时归档，并发布此版本，之后仍可在后台编辑或回滚。

海外灵感原有 60 个案例属于上一版 `viral` 素材，继续供浏览、收藏与主动引用，界面标为「旧版案例原型」。新生成任务不再自动把这些案例作为模型参考；用户主动选择时也只用于启发，不迁移旧案例的危险测试、产品事实或复杂拍法。历史稿件保留原版本标识与原结构，新稿件标记 `hiccai-pop v2.1.0`。

## 已接入

导航新增「海外创作」「海外灵感」，当前项目的资料与收藏可直接用于海外创作。用户提供的 Skill 在读取期间由 `viral-shorts-agent` 目录迁移为 `viral/skills/viral/SKILL.md`；接入的是名称为 `viral`、版本 1.0.0 的完整源文件，已复制到 `server/resources/viral-shorts-agent/SKILL.md`，运行不再依赖桌面目录。

- 默认三平台各一份：TikTok、Instagram Reels、YouTube Shorts。选单个平台时生成三个不同创意。
- 默认英文台词与中文翻译；也支持西班牙文、法文、德文搭配中译。可设置目标市场和 12–60 秒时长。
- 每个方案交付原创变化、创新算子、三个 Hook、目标语言口播、中译、连续秒级分镜、音效、屏幕文字、循环结尾、平台适配、讨论问题和拍摄清单。
- 产品名称即可开始探索；没有业务资料时明确标注待核对事实。参考中的参数、效果和经历不能迁移为用户产品事实。
- 复用已有原创任务、素材快照、模型主备路由、取消与退款：按自主创作规则收费，默认每批 15 积分。再来一批追加历史，并继承尚未过期的临时资料、参考和目标。
- 所有方案可打开完整创意，复制台词与中译、下载完整 TXT；CSV/XLSX 增加海外市场、语言、口播、中译、创新方法、Hook、循环和平台适配字段。
- 海外创作表单按账号/项目在当前标签页保存 24 小时，退出登录清除；库搜索请求防止切项目后旧响应覆盖当前数据。

## 海外灵感

- 导入 Skill 中 60 个原型、8 个品类，并保存原型编号、视觉结构、反射与视听手法。原型没有原始视频链接和可验证指标，界面标为「创意原型」，不会伪造作者、播放量或原视频。
- 原型按关键词与品类推荐，直接产品匹配优先于同品类匹配，理由可展开；这不是爆款概率。
- 手动收集 TikTok / Instagram Reel或帖子 / YouTube视频及Shorts链接，填写标题、字幕/说明和借鉴点。按规范化原始链接去重、按项目隔离；用户录入说明不冒充平台数据。
- 推荐和我的收藏可切换；收藏可取消，已收集内容仍保留。每条创意可直接带入海外创作，任务提交时保存参考快照。
- 实时关键词搜索复用 TikHub 密钥和后台端点配置。配置真实服务后支持三个海外平台，每次最多保留20个候选；同项目、同平台、同搜索词缓存15分钟。
- 搜索结果只是关键词候选，尚未验证爆款与完整画面。缺失互动数据保持空值，真实零值保留。YouTube 的 `duration=short` 表示小于四分钟，搜索词附带 `#shorts`，仍需查看原文确认是否 Shorts。

当前演示模式不发起付费搜索，也不调用真实创作或翻译模型；返回的是明确标记的结构模板。没有配置实时数据源时，原型浏览、收藏和手动链接收集均可使用。

## Skill 与接口

- 后台新增 `tiktok_original`、`instagram_original`、`youtube_original`、`overseas_original`。启动时一次性发布内置版本；之后后台发布和回滚仍沿用原机制。
- 原始 Skill 全文保留；追加 Daolook 交付约定，提供原创算子的应用定义并将危险演示转为安全道具，不伪造功效、评价、广告身份、热门声音或投放结果。固定留存/转化阈值不作为投放保证。
- `POST /api/overseas/create`：platform、topic、goal、market、language、duration、assets、temporary、requirements、reference_id；用 brief_id 继续一批。
- `GET /api/overseas/ideas`：project_id、query、category、platform、saved；推荐原型与项目内容。
- `POST /api/overseas/ideas`：archetype_id，或者原始 url、title、summary、mechanism、category。
- `PATCH /api/overseas/ideas/{id}`：project_id、saved；收藏状态。
- `POST /api/overseas/search`：project_id、platform、query。
- 数据表为 `overseas_ideas`、`overseas_searches`，启动自动创建；已有项目、内容和模型配置继续使用。

## 数据源核对

已按官方接口文档设置可覆盖的默认端点：

- [TikTok 视频搜索](https://docs.tikhub.io/186826070e0)：`/api/v1/tiktok/web/fetch_search_video`，keyword / count / offset。
- [Instagram Reels 搜索](https://docs.tikhub.io/387337819e0)：`/api/v1/instagram/v2/search_reels`，keyword。
- [YouTube 综合搜索 V2](https://docs.tikhub.io/431829299e0)：`/api/v1/youtube/web_v2/get_general_search_v2`，keyword / type / duration / sort_by。

后台「服务配置」中 TikHub 端点 JSON 可覆盖默认路径与参数。公开数据服务可能单独计费；本轮未使用实际密钥调用这三个新端点。需用实际账号验证权限、配额、返回结构与真实内容质量。
