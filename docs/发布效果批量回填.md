# 发布效果批量回填

在「项目资料」创建类型为「账号」的资料。在「我的创作」打开稿件的「发布与反馈」，登记实际发布时间、账号和平台作品 ID，也可通过已发布稿的「发布信息」补登。系统按项目、平台、账号和作品 ID 匹配到唯一稿件，并绑定当时的稿件版本。为同一作品选择「自然流量」「含付费流量」或「未区分流量」。一篇稿只跟踪一个平台作品。

在「我的创作」点「导入效果」，选择账号与平台，下载该账号的 CSV 模板。模板自动列出已绑定的作品。导出平台只有累计数据时，沿用「截至目前」；要补多个观察期，复制作品行后分别填写「24小时」「7天」或「30天」。固定观察期须在对应时长结束后录入。各行填写该时点的累计总数。

| 列 | 填写方式 |
| --- | --- |
| 平台、账号ID、作品ID | 保留模板原值。账号和作品 ID 带有纯文本前缀 `id:`，Excel/WPS 直接打开也能保留前导零、长数字和开头的连字符。导入同时接受原始 ID。自行整理平台文件时，先把 ID 列按文本读取，以免原始数字已被软件舍入。 |
| 稿件版本 | 模板带入发布时的版本号。平台表若有这列，值必须与绑定版本一致。 |
| 观察期 | 空白按「截至目前」处理。 |
| 浏览次数、有效咨询、订单数、投放金额 | 空白保留已有值，确实为零时填 0。支持只导入其中一列。投放金额单位为元。 |

保存为 UTF-8 CSV，选择文件后点「预览导入」。预览列出将被更新的旧值与新值。重复作品和观察期、账号错误、未绑定作品或尚未结束的观察期都会显示行号。修正后再次选择文件，有变更时点「确认导入」。整批一起保存；预览后若其他人修改了发布信息或效果，需重新预览。同一表重导会显示「数据已一致」。空指标行会跳过，已有客户追问与其他观察期的值会保留。每批最多 500 条有指标的记录。

在国内自主创作、参考创作或海外创作选「参考哪个账号的发布效果」，可看到该账号在相同平台和目标下已填写目标指标的稿数，分别列出自然、含付费及未区分流量。选定账号后，仅从同平台、同目标且实际有目标指标的正式发布稿中取最近更新的 12 篇。累计为 0 或本次发布的有效分期中填了 0 都计入；只有备注或其它指标的稿件不会占用名额；项目共享的产品资料与业务问题仍可参考。未指定账号时沿用项目范围。

这是 Daolook 的通用模板。首轮试点请把一个账号实际后台导出的列对应到模板。用同一运营者连续一周的导入与补录用时，以及看板的「7 天目标指标回填率」判断节省的工时和覆盖率变化。
