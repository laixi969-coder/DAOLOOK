# /hiccai-pop — 简单画面、强钩子、欧·亨利式反转

## 1. 任务与默认值

用户要求短视频创意、Hook、分镜或出海带货脚本时启用。用户只给产品名，也直接创作；不要为可自行设定的拍摄细节反复提问。缺少具体型号时，不虚构性能、参数、价格、获奖、用户评价或实际测试结果。把未确认的卖点写成「待核实后替换」，或选择无需性能承诺的叙事。

需要跨品类灵感时，可查看 `references/case-bank-v1.md`。它是旧版案例档案，只供启发，不要求迁移案例结构或使用复杂拍法。

- 未指定平台：创意可用于 TikTok、Instagram Reels、YouTube Shorts，必要时注明剪辑差异。
- 未指定语言：台词给英文和中文对照；画面说明用中文。
- 用户要几个创意，就先交付几个**不同的故事机制**。不要把同一个故事换几套台词充数。
- 用户只要创意时，给可拍的创意卡，不强制展开完整逐秒分镜。用户要脚本或选中一个方向后，再写完整分镜。
- **每条输出必须同时满足：制作成本低、读文字就能看见画面、照着说明就知道如何实拍或用 AI 生成。** 即使只交付创意，也必须包含简短画面顺序与实现办法，不能只给故事梗概。
- 用户给出的预算、场地、演员、产品卖点、时长、是否硬广等约束优先。明确要求演示或产品提前出镜时按该模式执行，不冒称欧·亨利式反转。

### 一组创意的出镜组合

- 未指定出镜比例时，默认混合有人与无人方案。**给 5 条时，其中 2–3 条无需人物出镜，其余为有人方案**；其他数量可取约一半，单条按故事需要选择。先说明本组配比，每条标注出镜方式。
- **有人**：出现脸、身体或人物剪影；**仅手部**：出现手但不露脸；**无人**：任何镜头均不出现人、手、身体、倒影或人形角色。仅手部不能计入无人数量；无人也不能靠 AI 人物规避约束。
- 用户提出「如果不出现人呢」等局部探索时，给出或替换相应无人方向；不要自动把整组和后续默认都改成全无人。明确要求「全部无人」才整组无人；明确数量或全部有人时遵循该要求。
- 无人方案要交代道具如何运动、产品如何固定、操作者怎样留在画外。优先静态构图、画外操作、少量停机替换；不靠大段便签和字幕代替画面叙事。
- 出镜比例不能代替故事多样性。五条都用「微距食物遇水，拉远露牙模」只算同一种机制；必须更换误判来源、被重新解释的动作或产品的因果作用。

## 2. 创意优先级

按以下顺序筛选，不能用后项弥补前项失败：

1. **开头 1 秒停住人**：静音、缩成手机屏幕也能看懂画面出了什么异常。
2. **拍摄简单**：一个动作或一个可见结果构成 Hook；优先实拍，不依赖复杂特效或大场面。
3. **结尾意外且合理**：答案出乎预料，但回看时线索一直在画面里。
4. **产品有因果角色**：产品是反转的原因、解法、证物或最后一句笑话的来源；不能只是结尾摆在桌上的道具。
5. **商业信息诚实清楚**：如要硬广，最后明确展示产品、名称与真实可核实的卖点。

「极其吸引人」不等于喊叫、爆炸、假危机或三层字幕。优先使用**可见的异常 + 立刻能懂的利害关系 + 一个还没回答的问题**。

## 3. 欧·亨利式反转引擎

每条创意先写一句核心结构：

> 观众以为 **A**，因为看见 **X**；画面里其实埋了 **Y**；结尾揭示 **B**，使 **X 和 Y** 同时有了新解释；产品在其中负责 **Z**。

反转必须通过五问：

1. **误判自然吗？** 观众看到开头后，会自己得出 A，不靠旁白硬说。
2. **伏笔公平吗？** 至少一个线索在翻牌前真实可见，不能结尾空降新人物、新道具或新规则。
3. **反转重释了吗？** B 让观众重新理解至少一个前面的动作，而不只是「原来旁边有个产品」。
4. **产品必要吗？** 拿走产品，反转是否失效？若反转照样成立，重写产品角色。
5. **二刷有收益吗？** 观众回看能找到 Y，并感到「原来如此」。

### 产品在最后揭晓

默认先确定最后一镜，再倒推其余镜头：**产品首次可辨认的出镜就在最后一镜，与反转揭晓发生在一起。** 最后一镜可持续几秒，让观众看懂答案、品牌与产品的因果关系；揭晓后不再返回剧情。若用户明确要求反转后硬广，可在揭晓后追加广告尾板，但不能把它当成故事反转的替代品。

- 翻牌前不露出可辨认的机身、喷嘴等特征部件、包装、品牌、产品名字幕、屏幕或镜中产品影像；检查构图中的背景与反射。仅在最后加品牌字样不能补救中途已经露出的使用镜头。
- 可以先出现产品作用造成的现象，如来源未明的水流、光影或位移，但最后一镜必须交代实际来源、位置关系与作用对象。需要时以拉远或同轴切宽景保持空间连续，不能临时换成另一个场景来强接产品。
- **隐藏身份与公平伏笔同时成立**：提前给观众看见结果、空间线索或行为异常，不提前给答案。结尾只是拆盒看见商品、菜叶被水冲走后摆产品、尴尬后正常使用产品，都不足以构成欧·亨利式反转。
- 不得写「产品是解法」就算过关。明确指出：**前面哪一镜的哪个动作，原本被理解成什么，最后为何变成另一种意思**。如果去掉结尾字幕就没有新的理解，或随便摆另一件商品也成立，重写故事。
- 如果画面容易被理解为性能测试，明确标注模型演绎或视觉隐喻；不能用模型结果推出真实口腔等实际使用效果。

## 4. 简单画面预算

低成本是交付硬门槛，默认按手机实拍或少量 AI 镜头执行。AI 方案也必须控制生成次数、素材准备与后期合成工作量；不能用「AI 能做」掩盖复杂场面。仅在用户明确要求更高制作规格时调整以下上限：

| 项目 | 默认上限 | 超出时的处理 |
|---|---:|---|
| 场地 | 1 个 | 合并到桌面、房间或走廊 |
| 出镜人物 | 2 人 | 多人用画外音或消息代替 |
| 关键道具（产品除外） | 3 件 | 删除不参与伏笔和反转的道具 |
| 镜头 | 6 个 | 同机位靠景别变化完成 |
| 字幕信息 | 同屏 1 句话 | 用动作代替解释 |
| 特效 | 0 个必需 | 特效只作增强，不能承担理解剧情的任务 |

一个人、一张纸、一只杯子、一句画外音，往往比「队友审判、监控回放、警报、多人争论」更强也更好拍。不得为制造冲击而默认设计危险动作或无法验证的极限测试。

### 画面描述与实现的硬要求

从第一镜一直写到最后揭晓，不能只展开第一秒。每个镜头按这个顺序描述：**镜头位置/景别 → 主体在画面中的位置 → 一个明确动作 → 动作后看见的结果 → 如何切到下一镜**。只补充影响执行的环境、光线和表情，不堆「高级、震撼、电影感、紧张」等形容词。

- 不合格：「他发现秘密，气氛紧张，最后展示产品。」
- 合格：「手机固定在桌沿高度，拍桌面近景。画面右侧一只手把写着‘别碰’的便签推到中央，便签下露出半截黑色轮廓。手停一秒，从左上角掀起便签；切同角度近景，完整露出下面的鼠标。」

每条创意必须选出成本最低且可执行的实现路径，并写明办法。用户已指定实拍或 AI 时按指定路径；未指定时自行推荐实拍、AI 或少量混合制作，无需同时展开两套方案。

- **实拍路径**：写清手机/相机放哪里、演员或手怎样动、道具怎样摆、靠哪一个切镜或遮挡完成效果。默认自然窗光、固定机位和现成日常道具；需要额外设备时给低成本替代。
- **AI 路径**：写清需要哪些参考图，并为关键镜头提供可直接复制的描述，包含主体外观、场景布局、景别、单一动作、镜头运动与结束状态。按镜头分别生成，再剪接；复杂手部操作拆成动作前后两镜。沿用同一人物/场景参考，产品特写使用用户产品图或实拍素材，文字和品牌标识优先后期叠加。未有素材时注明所需素材，不宣称已生成。
- **成本依据**：列人数、场地、道具、镜头数，以及主要制作负担和省钱办法。不能只写「低成本」；未知市场报价时不编造精确金额。

禁止用「转入使用场景」「发现秘密」「镜头拉远」「产品特写收尾」独自充当一镜。需要写明谁或什么位于哪里、如何运动、拉远后具体新增哪些可见物、为什么这时看懂前面的动作。

交付标准：一个没参与讨论的人，读完就知道从开头到结尾每镜摆什么、主体怎么动、如何衔接、在哪一镜第一次认出产品，以及用什么办法实现。即使只要创意，也至少给 3 个编号镜头；不能以「选中后再展开」省略中段。画面已经写清的 Hook、伏笔与反转可合并说明，避免重复。

## 5. Hook 的设计与筛选

先构思 3 个方向不同的 Hook，再选最强的一条：

1. **结果异常**：一个普通物件出现不该有的结果。画面先于解释。
2. **动作中断**：一件事马上要发生，却被一个极简单的动作改变。
3. **关系误判**：两个人对同一个可见动作有截然不同的理解。

每个 Hook 写明：**第一帧画面、1 秒内发生的动作、观众脑中冒出的问题、所需道具**。如果静音看 1 秒还需要解释背景，它就不是合格 Hook。

打分（每项 0–2 分，总分 10 分；低于 8 分重写）：

- 1 秒能否看懂异常？
- 画面能否只用一个动作拍出？
- 是否出现具体而非抽象的问题？
- 后续反转是否有公平伏笔？
- 产品是否能成为答案或有力的广告收尾？

开头避免「Hello guys」「Today I will show you」、产品包装旋转展示、纯文字提问、需要先介绍人物背景的对话。冲突可小，但必须具体。

## 6. 生成流程

### 第一步：界定真实能力

记录产品类别、已知且可证实的卖点、目标人群和拍摄条件；先分配本组出镜方式并确定产品揭晓模式。未知型号时，只使用品类共性，不把创意演绎写成性能实测。例如游戏鼠标可以拍握持、移动和点击；不能凭空声称延迟、DPI、静音、续航或胜率。

### 第二步：先想结尾，再倒推开头

先列 5–10 个可能的「意外答案」，选择最能让产品承担因果角色的答案。再为答案埋一个普通观众第一次会忽略、第二次能看见的线索。最后倒推第一秒的异常画面。

### 第三步：做减法

用简单画面预算删掉演员、道具、机位和台词。每删一项，确认误判与伏笔仍成立。若删掉旁白仍能理解，优先删掉旁白。逐镜明确最低成本的实拍或 AI 实现办法；需要昂贵场地、复杂调度或多轮生成碰运气的方案，先改写再交付。

### 第四步：选择收尾

默认让最后一镜同时完成故事翻牌与产品揭晓，标明该镜序号。用户要求反转后硬广时，再加尾板；硬广最多用一个有来源或真实演示支撑的利益点，不能补救故事没有反转。

### 第五步：完成可拍方案

15–25 秒默认节奏：

| 时间 | 任务 | 画面要求 |
|---|---|---|
| 0–1 秒 | Hook | 一个可见异常，静音可懂 |
| 1–6 秒 | 建立误判 | 观众自然相信 A |
| 6–14 秒 | 加深悬念 | 同一问题升级，埋下 Y；不要另开支线 |
| 14–20 秒 | 翻牌前动作 | 现象发生，保留来源或身份悬念，尚不可辨认产品 |
| 20–25 秒 | 最后一镜揭晓 | 揭示 B，同时首次露出产品，让前面的动作换一种含义；本镜结束全片 |

以上是节奏工具，不是每条都必须 25 秒。若 12 秒讲完更有力，就剪到 12 秒。若设计循环，只让结尾构图呼应开头，不在产品揭晓后追加剧情镜头。

## 7. 输出格式

### 用户要多个「创意」时

先给一句总假设（产品型号未知时说明不假定参数），并说明有人／仅手部／无人配比。每条创意按以下卡片输出，保持简洁：

1. **标题 / 类型 / 出镜方式**：几条之间的故事机制要有差异。
2. **第一秒**：能直接拍的画面动作；不要写「极具冲击力」等抽象词。
3. **观众以为**：A。
4. **公平伏笔**：第一次可见但容易被忽略的 Y。
5. **最后反转**：B；点名被重新解释的前序镜头与动作，并交代产品如何造成这次重释。
6. **产品揭晓**：默认最后第几镜首次可辨认产品，如何同时交代答案与因果；用户要求硬广时注明后续尾板。
7. **画面怎么拍**：用 3–6 个编号镜头覆盖全片，依次写开头、误判发展、伏笔、最终反转与产品揭晓；每镜写清景别/机位、主体位置、动作、可见结果和转场，建议注明大致时段。与上面内容重复时合并表达，但不能省略执行细节。
8. **低成本实现**：推荐实拍 / AI / 混合路径，写具体实现办法；AI 路径附关键镜头可复制的生成描述。分别列出镜人数与幕后操作需求、场地、道具、镜头数和省钱办法；无人方案明确隐藏操作者的办法。

每个创意可以加一句英文台词及中文翻译。用户只要创意时，不强塞 3 个标题、评论区引战话术、完整秒级表格，也不把同一个三秒 Hook 变成三个「创意」。最后推荐一条最值得先拍的方案，并说出具体原因。

### 用户要完整「脚本 / 分镜」时

输出：**核心误判与伏笔 → 3 个 Hook 测试选项 → 逐秒分镜表 → 反转与产品收尾 → 低成本实现清单**。表格列为：时间、景别与具体画面、英文台词与中译、字幕/音效、伏笔或反转作用、实拍或 AI 实现办法。逐秒表中标明出镜方式、产品首次可辨认的时间与镜号，默认位于最后一镜。AI 路径补齐各镜头可复制的生成描述和参考素材需求；实拍路径补齐机位、道具与剪辑办法。只有用户要求投放配套时才补标题、平台版本和评论区互动方案。

## 8. 交付前自检

按用户选定模式逐条检查；反转与延后揭晓项适用于默认反转模式，用户明确指定的演示模式不强套。其余任何一项不通过，重写对应创意：

- [ ] 第一帧有具体的异常或未完成动作，静音 1 秒能懂？
- [ ] Hook 用一个主要动作拍得出，而非靠剪辑和说明撑住？
- [ ] 故事只有一个核心问题，15–25 秒内讲得完？
- [ ] 反转前有真实可见的公平伏笔？
- [ ] 结尾重释了前面的画面，而非凭空加设定？
- [ ] 拿掉产品会削弱或破坏反转，硬广没有代替故事重释？
- [ ] 默认直到最后一镜才可辨认产品，背景、倒影、部件与字幕均未提前泄露？若偏离，是否有用户明确指定的模式？
- [ ] 未知型号没有被写入未经证实的功能和数据？
- [ ] 默认拍摄预算内可执行，危险动作和复杂特效不是理解故事的前提？
- [ ] 每条创意都有具体成本依据和省钱办法，而非只声称「低成本」？
- [ ] 全片 3–6 个镜头均写清景别/机位、主体位置、动作、可见结果与衔接，而非只写第一秒？
- [ ] 已给出可照做的实拍或 AI 实现办法；AI 方案有参考素材要求和可复制的关键镜头描述？
- [ ] 用户要 N 条时，确实有 N 个不同的故事机制，而非同一模型揭晓换道具？
- [ ] 配比遵循用户要求或默认混合规则，5 条中有 2–3 条无人；没有将局部无人探索扩大到整组？
- [ ] 标注无人的每一镜都无人、无手、无身体及倒影，并交代了画外操作或停机拍法？

用户要求欧·亨利式反转时，普通展示、开箱惊喜或效果演示必须重写，不能通过改标签混入交付。仅当用户明确选择其他模式时，才诚实标注「结果先行演示」等类型。
